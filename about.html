Como começou

A razão principal que tive para criar esse projeto veio de uma certa limitação que sofri usando um chromebook escolar, quando eu queria usar um programa-web sem internet eu acabava não encontrando muitas opções para o ambiente do navegador, foi com essa limitação que tive coragem de querer criar sites de programaas para usar no navegador de forma offline.
